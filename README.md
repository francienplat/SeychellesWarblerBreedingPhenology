pedfate.csv 
nesting success defined as fledglings that made it to 20 days old (18-20 on report so took upper limit) 
propFledged: calculated based on nest file alone, NoFledglings/ClutchSize 
propFledged_brd: calculated based on nest file alone, BroodSize/ClutchSize 
BrF: BirdID of BrF
BrM: BirdID of BrM
nrFl: number of FL
nrH: number of helper
nrSub: number of subordinates 
merged with pedigree 
nrpedrow: number of fl according to pedigree not accounting for lifespan 
nrpedfl: nr of fl according to pedigree after filtered for lifespan >20 days 
maxfl: max between NoFledglings and nrpedfl 
maxclutchsize: max clutch size between ClutchSize, BroodSize and nrpedrow 
propfl_true: maxfl / maxclutchsize
